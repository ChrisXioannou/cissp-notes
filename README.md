# CISSP Study Notes

Working notes for the CISSP exam, organised by domain. Written as decision rules rather than definitions, because the exam tests judgement under a qualifier (FIRST, BEST, MOST, GREATEST) more than recall.

Start with the exam technique section. The domain notes assume you already know how to read a stem.

## How these are written

Every section is built around the discriminator: the single fact that separates two plausible answers. Definitions are kept short because the exam rarely asks for one directly. Where sources disagree (Sybex and the ISC2 material do, in places), the conflict is flagged rather than resolved silently.

## Scope

Aligned to the ISC2 CISSP exam outline effective 15 April 2024, plus the AI security guidance published 2 April 2026.
