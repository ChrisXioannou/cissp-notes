# Ordered Lifecycles

> The generic arc behind all of them: **Plan, Understand, Build/Act, Verify, Operate, End**

If you blank on a specific list, place the described activity in that arc and pick the neighbouring option.

| **Lifecycle Order**          |                                                                                                   |
|------------------------------|---------------------------------------------------------------------------------------------------|
| **SDLC**                     | Initiation, Requirements, Architecture, Design, Code, Test, Integrate, Deploy, Maintain, Dispose  |
| **RMF (800-37)**             | Prepare, Categorize, Select, Implement, Assess, Authorize, Monitor                                |
| **Risk assessment (800-30)** | Prepare, Conduct, Communicate, Maintain                                                           |
| **BIA (Sybex)**              | Identify priorities, Risk identification, Likelihood, Impact, Resource prioritisation             |
| **BCP**                      | Scope, BIA, Recovery Strategy, Approval, Training, Test and Maintain                              |
| **IR (NIST 800-61)**         | Preparation, Detection and Analysis, Containment/Eradication/Recovery, Post-Incident              |
| **IR (Sybex 7-step)**        | Detection, Response, Mitigation, Reporting, Recovery, Remediation, Lessons Learned                |
| **Identity**                 | Create identity, Provision account, Provision access, Authenticate, Manage, Deprovision           |
| **Access control**           | Identification, Authentication, Authorization, Accountability                                     |
| **Change management**        | Request, Impact assessment, Approval, Build and test, Notify, Implement, Validate, Document       |
| **eDiscovery (EDRM)**        | Govern, Identify, Preserve, Collect, Process, Review, Analyze, Produce, Present                   |
| **Pentest**                  | Recon, Scanning/enumeration, Vulnerability assessment, Exploitation, Post-exploitation, Reporting |
| **Certificate**              | Generate keypair, CSR, RA verifies, CA signs, Publish, Use, Renew or Revoke, Expire               |

**Anchor sequences to logic, not order.** You cannot authorize an identity that does not exist. You cannot approve a change without an impact assessment. You cannot compute ALE without ARO. Pure lists disappear under stress; reasoned ones do not.
