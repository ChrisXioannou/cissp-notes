# AI Security

| **Domain**            | **Concepts**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| D1 Governance         | AI governance (acceptable use, model approval, human-in-the-loop). Algorithmic bias from skewed training data, a governance and ethics issue not a technical one. Shadow AI, same shape as shadow IT, CASB is the discovery control. AI vendor risk: a model provider is a processor, data sent to a model is disclosure, normal third-party due diligence applies. EU AI Act is risk-tiered (unacceptable, high, limited, minimal). GDPR Art. 22 covers automated decision-making                                                                                                                                                                                                                                       |
| D2 Assets             | Training data and model weights are classified assets, often the highest-value IP. Data provenance: where training data came from and whether you had the right to use it. Privacy techniques: differential privacy (inject noise), anonymisation (irreversible), pseudonymisation (reversible with a key, still personal data under GDPR), masking, synthetic data. Prompts and outputs are retained data                                                                                                                                                                                                                                                                                                               |
| D3 Securing the model | Prompt injection: attacker input overrides system instructions. Direct (typed) or indirect (hidden in a document or page the model reads). Defence is input/output filtering and least privilege on what the model may do. Data poisoning: corrupting training data, an integrity attack. Adversarial examples: crafted inputs causing misclassification. Model inversion (reconstruct training data from outputs) and membership inference (was this record in the training set), both confidentiality attacks. Model extraction: cloning by repeated querying. Explainability (XAI) supports governance but does not prevent misuse, a common distractor. Secure enclaves / confidential computing protect data in use |
| D5 Identity           | Non-human identities. AI agents and service accounts need identity, least privilege, credential rotation, and attributable actions. An agent acting with a human's full permissions is a privilege problem                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| D6 Testing            | AI red teaming: adversarial testing of model behaviour, distinct from network red teaming. Bias testing and model validation before deployment                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| D7 Operations         | AI for defence: UEBA, anomaly detection, alert triage. Model drift: performance degrading as live data diverges from training data, requires continuous monitoring. AI incident response: harmful model output is an incident; rollback to a previous model version is the corrective control                                                                                                                                                                                                                                                                                                                                                                                                                            |
| D8 Development        | AI-assisted coding risks: generated code may be insecure or hallucinate non-existent dependencies (slopsquatting, attackers register the hallucinated package names). MLOps pipeline security: model registry integrity, signed models, provenance. OWASP Top 10 for LLM Applications exists, know it by name                                                                                                                                                                                                                                                                                                                                                                                                            |
